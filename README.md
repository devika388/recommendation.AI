# Food Recommendation System

## Description

This project is a simple Python-based Food Recommendation System that recommends food items based on the user's preferences. The user enters their preferred cuisine (such as South Indian, North Indian, Chinese, Italian, or Desserts) and selects a spice level (Mild, Medium, or Spicy). The program then uses conditional logic to match the user's preferences and displays a list of suitable food recommendations.

### Features

* Accepts user input for cuisine and spice level.
* Recommends food items based on user preferences.
* Uses simple pattern matching with `if-elif-else` statements.
* Beginner-friendly and easy to understand.
* Demonstrates the basic concept of recommendation systems.

### Technologies Used

* Python 3

### Concepts Covered

* User Input
* Conditional Statements (`if`, `elif`, `else`)
* String Handling
* Pattern Matching
* Basic Recommendation System Logic

### How to Run

1. Clone or download the repository.
2. Open the project in your preferred Python environment.
3. Run the program:

   ```bash
   python food_recommendation.py
   ```
4. Enter your preferred cuisine and spice level when prompted.
5. View the recommended food items.

### Example Input

* Cuisine: South Indian
* Spice Level: Mild

### Example Output

* Idli
* Pongal
* Curd Rice

## Learning Outcome

This project demonstrates the fundamentals of building a recommendation system using user preferences and logical decision-making. It is suitable for beginners learning Python and serves as an introduction to recommendation system concepts.
